# v0.1 验证记录（2026-09-09）

这是首个可运行版本的本机验证，不是长期稳定性认证。

## 构建与单进程

- Visual Studio 2022 / MSVC 19.42，Windows x64 Release，CPU AVX2，静态 CRT / ggml。
- CTest 通过：环形缓冲回绕与溢出、VAD 句尾提交、重置、数字静音抑制、临时字幕合并、最终队列上限。
- 运行中的 `FunASRSubtitle` 正常响应，查询到的子进程数量为 0。
- 导入 DLL 仅为 Windows 系统库：gdiplus、SHELL32、WINMM、KERNEL32、USER32、GDI32、ADVAPI32。

## 识别回归

音频来自 whisper.cpp 的公开 `samples/jfk.wav`：16 kHz，11 秒，22 个英文参考词。
音频 SHA-256：`59dfb9a4acb36fe2a2affc14bacbee2920ff435cb13cc314a08c13f66ba7860e`。
参考文本见 `tests/english-reference.txt`。WER 使用小写化、去标点后的词级编辑距离；
替换、删除、插入均计入，不纠正识别词、不省略失败样本。

| 测试路径 | 结果 |
|---|---|
| 常驻 SenseVoice，整段文件，连续 3 次 | 三次文本相同；首次输出 WER 0/22 = 0% |
| 同一实例加载耗时 | 216 ms |
| 三次整段推理耗时 | 410 / 417 / 407 ms |
| 有限窗口 VAD + 临时更新 + 最终分段 | 3 个最终句，WER 0/22 = 0% |
| 真实 WASAPI 系统回放 + GUI | 3 个最终句，WER 0/22 = 0% |
| GUI 测试中的最终句推理耗时 | 103 / 77 / 221 ms |

GUI 测试确实通过系统输出设备播放样本，再由 WASAPI loopback 采集，没有把测试 WAV
直接当作实时输入喂给识别器。GUI 的最后一帧通过同一个绘制函数输出为图像并检查换行布局。

## 短时运行

- GUI 会话约 45.3 秒，退出码 0；其中只播放了 11 秒音频，其余主要为静音。
- 采样到的峰值工作集约 277.5 MiB。
- 会话平均占整机 16 个逻辑处理器约 1.65%；这个值包含大量静音，不能代表持续讲话负载。
- 之前一次测试观察到短非语音误触发。增加数字静音能量门限和模型非语音标签过滤后，
  本次复测没有额外的最终字幕；仍不能保证消除提示音、音乐、噪声造成的误识别。
- 临时字幕出现过 `America` / `Watch`，最终句修订为正确结果。部分文本会修订，不能把临时 WER 当成最终 WER。
