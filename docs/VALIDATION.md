# v0.1 验证记录（2026-09-09）

这是首个可运行版本的本机验证，不是长期稳定性认证。

## 构建与单进程

- Visual Studio 2022 / MSVC 19.42，Windows x64 Release，CPU AVX2，静态 CRT / ggml。
- CTest 通过：环形缓冲回绕与溢出、VAD 句尾提交、重置、数字静音抑制、临时字幕合并、最终队列上限。
- 运行中的 `FunASRSubtitle` 正常响应，查询到的子进程数量为 0。
- 导入 DLL 仅为 Windows 系统库：gdiplus、SHELL32、WINMM、KERNEL32、USER32、GDI32、ADVAPI32。

## 识别回归

音频来自 whisper.cpp 的公开 `samples/jfk.wav`：16 kHz，11 秒，22 个英文参考词。
音频 SHA-256：`59dfb9a4acb36fe2a2affc14bacbee2920ff435cb13cc314a08c13f66ba7860e`。
参考文本见 `tests/english-reference.txt`。WER 使用小写化、去标点后的词级编辑距离；
替换、删除、插入均计入，不纠正识别词、不省略失败样本。

| 测试路径 | 结果 |
|---|---|
| 常驻 SenseVoice，整段文件，连续 3 次 | 三次文本相同；首次输出 WER 0/22 = 0% |
| 同一实例加载耗时 | 216 ms |
| 三次整段推理耗时 | 410 / 417 / 407 ms |
| 有限窗口 VAD + 临时更新 + 最终分段 | 3 个最终句，WER 0/22 = 0% |
| 真实 WASAPI 系统回放 + GUI | 3 个最终句，WER 0/22 = 0% |
| GUI 测试中的最终句推理耗时 | 103 / 77 / 221 ms |

GUI 测试确实通过系统输出设备播放样本，再由 WASAPI loopback 采集，没有把测试 WAV
直接当作实时输入喂给识别器。首轮 GUI 的最后一帧通过同一个绘制函数输出为图像并检查换行布局。
这只能验证识别与绘制内容，不能证明窗口出现在用户当前桌面；首轮启动所在桌面的问题见下方修复记录。

## 短时运行

- GUI 会话约 45.3 秒，退出码 0；其中只播放了 11 秒音频，其余主要为静音。
- 采样到的峰值工作集约 277.5 MiB。
- 会话平均占整机 16 个逻辑处理器约 1.65%；这个值包含大量静音，不能代表持续讲话负载。
- 之前一次测试观察到短非语音误触发。增加数字静音能量门限和模型非语音标签过滤后，
  本次复测没有额外的最终字幕；仍不能保证消除提示音、音乐、噪声造成的误识别。
- 临时字幕出现过 `America` / `Watch`，最终句修订为正确结果。部分文本会修订，不能把临时 WER 当成最终 WER。

## 字幕栏不可见修复与复测（2026-09-09）

用户报告“already running”但看不到字幕栏。只读窗口诊断确认：旧进程 4472 的窗口
在 `CodexSandboxDesktop-...` 隔离桌面上，`IsWindowVisible=1`；用户 `Default` 桌面找不到这个窗口。
旧进程仍占用会话内单实例互斥量，所以用户重复打开 EXE 只得到“已经运行”的弹窗。
因此本次实际根因是先前自动启动使用了隔离桌面，不能将窗口可见标志或离线 PNG 当作桌面交付证据。

已结束隔离桌面旧实例，在用户 `Default` 交互桌面启动项目根目录的新版 EXE。同时增加：

- 重复打开 EXE 通知已有窗口显示；左键托盘、菜单和 `Ctrl+Alt+S` 均可恢复位置并解锁点击穿透。
- 明确设置窗口可见和置顶状态，将恢复位置约束到鼠标所在屏幕工作区。
- 直接绘制到保留预乘 alpha 的 32 位 DIB，检查 `UpdateLayeredWindow` 返回值；无声音时显示等待提示。
- 找不到已有窗口时，提示可能在其他桌面，提供结束旧进程后重新打开的处理方法。

最终构建 CTest **2/2 通过**。新增测试启动真实 GUI EXE，但不加载模型或音频设备：
隐藏启动、隐藏并移出屏幕且启用点击穿透后的重复打开、最小化恢复，均验证可见、
工作区内、置顶、可交互、图层更新成功，并验证图像包含完全透明、半透明和不透明像素。
测试使用独立窗口类及互斥量，不与正式实例冲突。

用户桌面的最终运行诊断为 `desktop=Default, found=1, pid=12444, visible=1`，
窗口物理坐标 `(1420,1804)-(2420,2034)`。重复启动进程退出码为 0，留下 **1 个 GUI 进程**。

本次另做 20 秒 GUI 会话，通过系统输出播放同一 JFK 样本并经 WASAPI 采集：
3 条最终字幕，WER **0/22 = 0%**，最终句推理时间 **96.1 / 77.8 / 203.7 ms**。
GUI 状态记录为 `visible=1, layered_update=1`。仍未测严格的端到端显示延迟，
